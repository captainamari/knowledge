## 每次运行

1. 读取最新协议与账户，检查前次是否提交完整、是否存在待处理订单或过期估值。
2. 核实交易日、实际时间、公司公告/宏观事件、三位作者的最新修正和独立市场证据。
3. 先决定是否交易、写下理由和风险，再获取符合协议的后续报价；不满足成交门槛就不成交。
4. 成交、费用、现金、持仓和订单状态在同一次 account.json 更新中结账，并校验恒等式，再写日报。
5. 重新读取远端验证；仅对已核验模拟成交发操作通知，注明“模拟”，包括价格/时间/数量/理由/风险/账户变化。计划、待单、取消单不得说成买卖完成。
6. 每个有效交易日即使不交易，也记录“继续持有/保持现金”的判断及原因。无操作无需重复通知；重要账本或数据事故需说明。收盘复盘与盘中成交分开。

已启用工作日调度：以 **America/New_York 10:20、16:20 为起点的弹性窗口（约一小时）**，分别做盘中决策和日终估值/次日计划，自动适应纽约夏令时。首次安排为2026-10-30日终。调度设置已由创建者核验，不代表首次运行已经完成；实际运行可能延后，必须用真实时间判断市场是否仍开盘。周末和休市日不伪造日线，早收盘日按交易所日历处理。

交易、基准和数据缺口从开始日起连续保留，不重置亏损历史，不把未交易日从绩效窗口剔除。规则修改须版本化、写原因及生效时间，仅向前生效。
