# 执行与风控协议 v2.0：高风险独立模拟实验

本版本在首次提交远端并全文核验、且唯一账本登记v2生效事件后才对新决策生效；具体生效时间与提交见唯一账本的 PROTOCOL_CHANGE 事件。此前 v1.1 [原文归档](PROTOCOL-v1.1.md)及全部历史保留，不重算过去交易、不重置本金或峰值。生效时账户现金10,000美元，持仓、订单和成交均为零。

## 1. 实验目标与授权边界

用户将本盘明确定位为高风险模拟实验，并要求决策依据为市场客观信息和 arch 的独立逻辑；用户观点与被关注作者的说法只作线索，不自动转为订单，不复制用户真实持仓。采用专业交易研究的框架，不冒充真实华尔街任职资历。

- 始终是纯模拟：不连接券商、不执行真实交易、不购买数据、不取得用户交易凭据。
- 初始本金仍为10,000美元，无追加注资。追踪累计净收益、最大回撤、费用、持仓风险、执行失败与基准。
- “三个月收益100%”是用户提出的挑战参照，不是保证、必达约束或为了冲目标必须下注的指令。若从v2生效时观察三个月，单独展示阶段表现；原始账户全历史同时保留，不用阶段起点掩盖亏损。
- 提高风险预算，不等于必须满仓。现金仍可以是独立决策，但必须分别说明投资判断和具体数据限制，不能用“缺SPY基准”概括所有证券都不可交易。
- 本版本数值为 arch 选择的实验参数，不冒称用户逐项指定。集中持仓、跳空、长期回撤或期权归零均可能使实验遭受重大损失。

## 2. 可交易工具、现金与会计

- 整股美国上市股票，以及非杠杆、非反向美国上市ETF。无保证金融资、无借款、无股票卖空，不使用杠杆/反向ETF。
- 期权仅买入标准、未调整的美股/ETF Call或Put，再卖出平仓；不卖出开仓、不裸卖、不建立价差组合。长权具有杠杆且权利金可损失100%；无合格数据不模拟成交。
- 仅用已结算现金。买单按最大承诺成本预留现金；卖出净额进入未结算应收，按适用T+1结算营业日转现金，不能以同日卖出款立即再买。相关日历须核实。[SEC T+1](https://www.sec.gov/compliance/risk-alerts/shortening-securities-transaction-settlement-cycle)
- 现金利率固定0%，税前绩效，不估算税款。股息按核实除息资格计应收，支付日转现金；分拆只改数量/单位成本，不制造盈亏。未厘清公司行动时冻结相关证券新单。
- 沿用FIFO：买入费用计入批次成本，卖出费用扣净卖出收入。cash_total = settled_cash + unsettled_cash；equity = cash_total + securities_market_value + dividend_receivable；total_pnl = equity − net_contributions = realized_trading_pnl + unrealized_pnl + dividend_income。费用不重复扣减。

## 3. 高风险预算与停止条件

以下均以前次已核验正式净值为分母，计入已有持仓及所有待单的最大承诺，所有条件同时满足：
- 单一证券及以其为标的的长权合计成本≤35%；同一行业/共同风险主题≤70%；全部股票、ETF、长权及待单总成本≤95%，至少5%现金。ETF按实际暴露保守归类，长权按其标的归入同一主题并计全部成本；不能用多只高度相关ETF或期权绕开主题上限。期权另外列出标的名义敞口及可得Delta，名义敞口不是最大损失，也不把“只花少量权利金”说成低风险。
- 股票/ETF单笔计划风险≤5%，组合全部计划风险≤12%。组合计划风险包括所有股票/ETF的预定退出风险，以及每笔长权的全部权利金和费用；不得把期权风险漏算或用对冲关系抵减。计划风险按买入最高限价至预设退出阈值、退出不利滑点、双边费用估计，不把它叫“最大损失”。下一开盘退出或跳空可远超该数字。
- 单笔期权全部权利金及费用≤5%，全部长权成本≤10%；不能临时为凑一张合约提高预算。开仓剩余14–180个日历天，计划最迟提前5个交易日退出，排除0DTE。
- 正式净值相对上一有效日终净值下降达到6%时停止新增风险，包含未实现盈亏与已计费用；如果前一有效估值跨多日，标为多日区间而非单日。从历史峰值回撤达到25%时暂停新增风险，先完成书面复盘并明确恢复条件。遇缺失估值不能声称未触发。暂停不抹去原订单已经发生的模型事件，也不保证亏损止于25%。
- 开仓必须有独立论点、持有期限、预先写明的价格/事实失效条件、退出计划、反面情景和仓位理由。禁止因亏损自动摊低成本；加仓是新的独立决策。

## 4. 事件风险

- 公司财报、FOMC、就业/通胀等时间须核对原始日历。未来两个交易日内有已核实单股财报时，可选择承受事件，但该股总成本≤20%、计划风险≤2.5%；长权全部成本≤2.5%。没有明确写出事件风险与最坏情景，不允许跨财报新开该股风险。
- 预定FOMC决议前后、就业/通胀等宏观事件不是一律禁止交易，但每笔相关订单必须写出是否跨事件及能接受的跳空风险；若无法提前决定，就等事件后再作未来订单，不能先下单再根据结果选择性撤回。
- 突发战争、制裁或停牌须分开核验事实、已有暴露与能否执行。黄金、债券或期权不被默认视为有效对冲。
- 本盘不是全天监控，退出阈值是检查时触发的交易计划，不是交易所止损单；不能假称两次检查之间按止损价成交。[SEC止损风险](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-15)

## 5. 股票/ETF：统一前瞻的次日开盘模型

### 5.1 订单承诺
1. 只在前一正常交易日实际收盘后、当日23:59 America/New_York以前，将下一正常交易日的完整订单提交唯一账本并远端核验。周末不改周五承诺。当天开盘已经发生后不能补建当天订单。
2. 订单包含唯一ID、decision_at、规则版本、目标会话、证券身份、方向、整股数量、最高买价/最低卖价、固定来源URL、理由/退出、费用/容量/风险预算。将“已提交待模型成交”与“已成交”严格区分。
3. committed_at以实际Git提交时刻为准，verified_at与commit SHA记入后续确认事件，核验也必须早于前日23:59 ET；只在已经远端核验的前提下执行。未核验订单不能产生模型成交。
4. 买入预留数量×最高限价+买入费，卖出预留持有股数。提交先后顺序固定，不重复使用资金或股数。

### 5.2 固定数据路线及成交
- **v2新订单统一使用MarketWatch该证券download-data页面中目标美东交易日的Daily Open字段。**股票路径 /investing/stock/{ticker}/download-data，ETF路径 /investing/fund/{ticker}/download-data；每单必须事先锁定完整URL。字段须为美元、正确证券、正确日线日期，排除Weekly/Monthly、NAV、adjusted close、盘前/盘后头部报价。
- 该选择是因为旧路线长期不可用，而此提供商有可读取、可保存的日线字段；是前瞻的可复现模型，不是官方竞价或真实可成交保证。**不在单笔成交时切换来源，不因价格不利改用Nasdaq/Yahoo/发行人或另一日。**同一交易日/时段/币种且口径兼容的独立来源价格差若超过max(0.02美元,固定来源字段×0.0005)，或日期/证券/公司行动口径不一致，则标blocked_price_conflict并厘清；小于阈值的差也保留，不平均或挑较有利值。成交量差异仅作数据限制，不据此替换已经冻结的容量样本。
- 下单前必须证明固定URL能读取适用Daily Open及日期；允许最新完整日线滞后最多2个正常交易日，并记录滞后。它仅证明路线可用，不证明目标日未来数据一定会出现。
- 公司行动、币种、证券身份或拆股口径不清时冻结相关证券，不把调整前后价格直接拼接。本实验使用该提供商当时展示的每股Daily字段，不宣称已验证完整复权算法。已知拆股/合并或数值突变必须先核对；不得以“算法未公开”默默改用另一源。保存首个合格目标日OHLCV快照和观察时间；后续供应商修订通过correction记录，不挑有利版本。
- 模型买价=Open×1.002，向上取到美分；卖价=Open×0.998，向下取到美分。股票/ETF每笔每侧费用=max(1美元,股数×0.005美元)，滑点另计。
- 超过买入限价或低于卖出限价则整单not_filled_open_limit，不看日内高低点，不事后减量，不改成收盘/次日成交。每单只计算一次。
- 目标Open可能延后才可读；区分model_execution_at（目标正常开盘）、observed_at和recorded_at。缺数标blocked_data、保留原日期与资金预留，冻结新增风险，待同一目标字段恢复后按冻结规则补证。不得填虚构价格或移动目标日。

### 5.3 容量、不可选择性撤单及退出
- 核验最新20个可得的正常交易日日线成交量，最后一天不得早于提交日之前第2个正常会话；平均日成交额代理值（固定用每日Daily Close×Volume的20日算术平均，并非逐笔成交金额）≥2000万美元，订单数量≤平均日成交量0.01%向下取整。完整记录20行日期/计算；无足够资料不下单。该过滤和20bp滑点不是开盘流动性认证。
- 已承诺订单不因后来价格、普通新闻、宏观数据或财报结果改变。仅在目标整体休市、正常开盘停牌/无开盘、改变单位的公司行动、撤市/身份不明，或用户明确暂停/终止时，按真实时点留证取消；不删除已经发生的模型成交。普通分红不是取消理由。
- 股票退出仍使用下一正常会话开盘模型。价格阈值在实际检查时发现后形成下一合法窗口订单，不保证盘中急售或按阈值价成交。时间止盈/止损也须提前提交。
- 额外采用日终Close作为退出触发时，必须指定目标日期的同一MarketWatch Daily Close；若预设条件在晚到数据中才被确认，只能在实际确认后提交未来订单，不补造已经错过的退出。

## 6. 期权：真实时段的严格报价模型

**能力闸门：当前尚未证明能够持续取得执行所需实时双边数量及收盘前5分钟有效bid，期权新单暂禁用。**只有实际核验完整来源与执行/收盘估值流程，并将能力验证证据及前瞻启用时刻登记账本后才能启用；日常10:20/16:20两次窗口本身不能代替临收盘数据。不得为了使用期权降低新鲜度门槛或事后回填bid。

- 每单预先固定具体实时报价来源和有效检查窗口；先提交并核验订单，再读取报价。必须是正常连续交易时段；双边报价时间不早于订单核验、距获取≤60秒，有bid/ask、各档数量及单位。
- 核验合约、到期、行权价、Call/Put、乘数和交割内容；当日成交量≥100、最近公布未平仓≥500，bid>0且非交叉，点差≤中间价10%，合约数量≤相应一档数量10%向下取整。
- 买入=ask+max(每股0.05,ask×1%)，卖出=bid−max(每股0.05,bid×1%)且不低于0；按最小报价单位向不利方向取整。费用每笔每侧=max(1美元,合约数×0.65美元)+每份0.10美元。
- 按实际观察顺序使用事前固定来源在有效窗口内的首个满足上述时效/字段/流动性条件的报价，记录所有先前不合格观察及原因；不能从多个合格报价中选价。首个合格报价若不满足限价/现金/风险，整单结束不成交，不能跳过它等待更有利报价；无部分填单。无实时合格数据，不用last、中点、理论价或日线填单；当天结束未成交即到期。
- 不模拟实物行权。未能按提前5个交易日计划退出时保留失败和风险；到期按事前“模拟不行权”规则归零，剩余成本全部实现损失，即使价内也不虚构现金结算。此保守约定可能牺牲内在价值，与真实券商自动行权不同。[OIC](https://www.optionseducation.org/optionsoverview/options-basics)

## 7. 估值、基准与历史连续性

- 新股票/ETF持仓日终统一用固定MarketWatch Daily Close标记，注明提供商日终字段而非交易所官方成交验证；另有官方价可作核对，不挑有利来源。长权用收盘前最后5分钟的有效bid，不能用last/中点。
- 无该会话合格标记：保留上次标记及日期并标stale，正式equity/P&L/日收益设null；可另列last_known_estimate，不能把成本当最新市值。冻结新增风险，不更新正式峰值/回撤。
- 目标开盘尚未到或已确认未成交的订单只预留现金，不改变净值、费用或盈亏。目标开盘已过但成交结果待证时，状态为execution_pending_evidence，不等同未成交；正式净值、收益和回撤设null，另列last_known_estimate，冻结新增风险，待原目标字段补证后更正受影响历史。每笔成交/费用/现金/批次/订单状态同次原子提交；历史错误用带引用的更正，不能抹掉亏损。
- 所有原始净值快照、10/30起累计收益和历史峰值继续保留。单日/多日区间收益须如实区分；不能仅报告盈利阶段。
- **旧SPY基准继续锁定11月2日Open及v1.1原来源门槛，缺口保持null。不得用新MarketWatch规则追补成旧规则合格基准。**
- 另开透明的v2阶段比较：阶段起点预定2026-11-05正常会话Open，SPY来源固定MarketWatch Daily Open/Close，10,000/P0单位、零费、不再投资现金股息；未取得目标Open前为null。不因仅缺数据改日期。v2阶段表现不能代替全历史或宣称已经达到三个月目标。
- SPY/现金基准与本盘滑点、费用、期权风险不同；至少同时展示收益、最大回撤、费用、投入和样本数。少量样本不能证明稳定能力。

## 8. 运行、通知与版本

- 保留纽约工作日10:20/16:20弹性窗口，按真实时刻和[NYSE日历](https://www.nyse.com/markets/hours-calendars)判断时段；早收盘、延迟和遗漏必须真实记录。
- 从四位观察作者分别取线索，先查最新修正，再核对公司、宏观原始披露和市场字段；不将用户意见或作者仓位直接变成订单。
- 每次检查同一目标事件与订单ID，提交前读取远端并核对分支版本；用expected_sha防并行覆盖，冲突重读而非强推。账户和对应日志同次提交，提交后全文验证。
- 新订单/成交/取消/风险规则变化通知用户；待单不得称成交。没有新操作仅记账，重要新阻塞说明一次。
- v1/v1.1原文和记录保留。v2仅对远端核验以后的新决策生效：提高集中度、风险预算与允许的事件暴露；为未来订单固定可读取的提供商模型；不追溯重算历史，不为已知涨跌创建旧订单。
